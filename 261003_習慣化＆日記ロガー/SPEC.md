# 習慣化＆日記ロガー 仕様書

2026-10-03 grill-me セッションでの決定事項（経緯は [log_grillme_261003-1.md](log_grillme_261003-1.md)）。導入手順は [SETUP.md](SETUP.md)。

## 1. 概要

| 項目 | 内容 |
|---|---|
| 目的 | 毎日の習慣の実施有無とコメント（日記）を記録し、達成率を振り返る |
| 利用者 | 本人のみ（iPhone の Safari。ホーム画面に追加して起動） |
| 実行環境 | Google Apps Script（GAS）のWebアプリ。アクセスは「自分のみ」。貼り付けを楽にするため、ファイルは Code.gs と index.html の2つだけにする（タイムゾーンはコード内で Asia/Tokyo を指定するので、マニフェスト appsscript.json の編集は不要） |
| データ | Google スプレッドシート「習慣化ログ_データ」（Drive の「習慣化ログ」フォルダ内） |
| 出力先 | Google Drive の「習慣化ログ」フォルダ（CSV） |
| 格納先 | `261003_習慣化＆日記ロガー/` |
| 日付 | すべて日本時間（Asia/Tokyo） |

GAS にした理由：「23:59 の確定」と「週次の自動出力」は、アプリを開いていない時間に動く必要があり、静的サイトでは実現できないため。

## 2. 画面（1ページ）

上から順に、ダッシュボード → 日ごとの表 → 今日の入力。上部のバーに「今日」（入力欄へ移動）「出力」「設定」のボタン。

### 2.1 ダッシュボード
- 数値：今日の達成率（n / 全項目）、直近7日の平均、直近30日の平均
- 達成率グラフ：**日別の点＋7日移動平均の折れ線**。期間は 7日／30日／90日 の切替（初期は30日）。タップした日の日付・日別達成率（n/全項目）・7日平均を表示する。今日の点は白抜き（入力中）
- 達成率 ＝ チェックした項目数 ÷ その日の入力対象の項目数

### 2.2 日ごとの表
- 行＝日付（新しい順）、列＝日付・達成率・各項目。最初は30日分、「もっと見る」で30日ずつ過去へ
- ✓＝実施。コメントのあるセルは黄色＋右上の印でハイライトし、タップでコメントを表示する
- 項目の列名は現在の名称。終了した項目は右端に並び、対象外の日は「–」
- 月曜の行の下に太線（週の区切り）。今日の行は色付きで「今日」と表示
- 表は枠内でスクロールする（下の入力欄に届きやすくするため）

### 2.3 今日の入力
- 今日の入力対象の項目ごとに、チェックボックスとコメント欄（改行可・内容に合わせて伸びる・5000字まで）
- 入力済みの内容が表示され、その日のうちは何度でも追記・修正できる
- **自動保存**：チェックは押した瞬間、コメントは入力が1.5秒止まったときか欄を離れたときに保存。項目ごとに「未保存／保存中…／保存済み HH:MM」を表示。失敗時は「タップで再保存」
- 日付をまたいで開きっぱなしにしていた場合、保存はサーバー側で拒否し、「日付が変わりました」と表示して今日の画面を読み込み直す。アプリに戻ってきたとき（画面の表示切替時）にも日付を確認する

### 2.4 設定
- 項目名の変更（欄の外をタップで保存。30字まで。終了していない項目と同じ名前は不可）
- 並べ替え（↑↓）
- 項目の追加：今日から入力対象になる
- 項目の終了（削除の代わり）：**明日から**入力欄と達成率の分母から外れる。過去の記録は残る。今日追加したばかりの項目は今日から外れる。最後の1項目は終了できない
- 終了した項目の一覧

### 2.5 CSV出力
- 開始日・終了日を指定して出力（初期値：今週月曜〜今日）。今日の分は入力中の内容で含める。期間は記録開始日〜今日に丸める
- 出力後に Drive のファイルへのリンクを表示
- 週次の自動出力の説明と最終出力日時、「習慣化ログ」フォルダへのリンク

## 3. 確定・リセットと自動処理

- 記録は日付ごとに持つ。日付が変わると、新しい日の空の入力欄が表示される（＝リセット。項目名はそのまま）
- 確定した過去の日は**修正不可**（画面では閲覧のみ。どうしても直したいときはスプレッドシートを直接編集する）
- 毎日 **0時台**（0:05 前後）にトリガー `dailyJob` が動き、
  1. 前日までの未確定の日を確定する。**一度も入力しなかった日・項目も「実施なし」として行を作る**（達成率0%）
  2. 確定済みの月〜日の週のうち、未出力の週をCSV出力する（＝毎週月曜0時台に先週分）
- 「23:59に確定」は、日付が変わった時点で保存を拒否することで守る。トリガーは0時台に後処理を行う
- トリガーが動かなかった日があっても、アプリを開いたとき（`getAppData`）に同じ処理を行って埋める

## 4. CSV

| 種類 | ファイル名 | 期間 | 同名ファイル |
|---|---|---|---|
| 週次（自動） | `習慣化ログ_2026-09-28_2026-10-04.csv` | 月〜日（使い始めた週は開始日から） | 上書き（古い方はゴミ箱へ） |
| 手動 | `習慣化ログ_手動_<開始>_<終了>_出力<yyyy-MM-dd-HHmm>.csv` | 指定した期間 | 新規作成 |

- 1行＝1日×1項目。列：`日付, 曜日, 項目名, 実施(1/0), コメント`
- 項目名は**その日の名称**（名称変更前の日は旧名称のまま）
- UTF-8（BOM付き、Excelで文字化けしない）、改行はCRLF、全フィールドを `"` で囲む（コメント内の改行もそのまま入る）

## 5. データ（スプレッドシート）

すべてのセルを書式なしテキストで保存する。先頭が `=` の文字列は数式にならないよう、先頭にゼロ幅スペースを付けて保存し、読むときに外す。

| シート | 列 | 内容 |
|---|---|---|
| items | id, name, order, start, end | 項目。id は内部ID（デフォルトは i1〜i5）。start＝入力対象になった日、end＝最後に入力対象だった日（空＝継続中） |
| records | date, itemId, itemName, done, comment, updatedAt | 日×項目の記録。itemName はその日の名称（当日中の名称変更は反映）。done は 1/0 |
| days | date, total, done, rate, finalizedAt | 確定した日の集計（項目数・実施数・達成率） |

スクリプトプロパティ：`FOLDER_ID` `FOLDER_URL` `SS_ID` `START_DATE`（記録開始日） `LAST_FINALIZED`（最後に確定した日） `LAST_EXPORTED_WEEK_END`（最後に出力した週の日曜） `LAST_WEEKLY_EXPORT`（最後の自動出力日時）
