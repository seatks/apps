# 導入手順（Google Apps Script ＋ iPhone）

**PC のブラウザ（Chrome など）**で手順1〜5を行い、最後に iPhone でホーム画面に追加します。所要時間は15分ほどです。

貼り付けるファイルは次の **2つだけ** です。

| ファイル | 中身 |
|---|---|
| `gas/Code.gs` | サーバー側の処理（記録の保存、毎日の確定、CSV出力など） |
| `gas/index.html` | 画面 |

> `appsscript.json`（マニフェスト）の編集は**不要**です。日本時間はコードの中で指定しています。

---

## 1. プロジェクトを作る

1. https://script.google.com を開き、記録に使う Google アカウントでログインする
2. 左上の **「＋ 新しいプロジェクト」** を押す
3. 新しいタブでエディタが開く。左上の **「無題のプロジェクト」** という文字を押し、名前を `習慣化ログ` に変えて「名前を変更」

このとき、画面の左側の「ファイル」の下に `コード.gs` が1つだけあり、中央に次の3行が入っています。

```js
function myFunction() {

}
```

## 2. `Code.gs` の中身を貼り付ける

### 2-1. GitHub でコードをコピーする

1. PC のブラウザの別タブで次のページを開く
   https://github.com/seatks/apps/blob/claude/habit-diary-logger-spec-rkjgx3/261003_%E7%BF%92%E6%85%A3%E5%8C%96%EF%BC%86%E6%97%A5%E8%A8%98%E3%83%AD%E3%82%AC%E3%83%BC/gas/Code.gs
2. コードが表示されている枠の **右上** にある、四角が2つ重なったアイコン（**「Copy raw file」**）を押す
   - これでファイルの中身がすべてコピーされる（画面の端から端までドラッグして選ぶ必要はない）

### 2-2. エディタに貼り付ける

1. Apps Script のタブに戻り、左側の `コード.gs` を押して開く
2. 中央のコードの部分を1回クリックし、**Ctrl+A**（Mac は **⌘+A**）で全部選ぶ
3. **Ctrl+V**（Mac は **⌘+V**）で貼り付ける
   - `function myFunction() { }` は消えて、`// 習慣化＆日記ロガー（Google Apps Script）` で始まる長いコード（約500行）に置き換わればOK
4. **Ctrl+S**（Mac は **⌘+S**）で保存する（上部のフロッピーディスクのアイコンでもよい）

ファイル名は `コード.gs` のままで構いません。

## 3. `index.html` を作って貼り付ける

### 3-1. HTMLファイルを作る

1. 左側の **「ファイル」** という文字の右にある **「＋」** を押す
2. 出てきたメニューから **「HTML」** を選ぶ
3. ファイル名の入力欄が出るので、`index` と入力して **Enter**
   - `.html` は自動で付くので入力しない
   - 名前は必ず小文字で `index`（違う名前だと画面が表示されません）
4. 左側に `index.html` ができ、中央に `<!DOCTYPE html>` で始まる短いひな形が表示される

### 3-2. GitHub でコピーして貼り付ける

1. 別タブで次のページを開き、2-1 と同じく右上の **「Copy raw file」** を押す
   https://github.com/seatks/apps/blob/claude/habit-diary-logger-spec-rkjgx3/261003_%E7%BF%92%E6%85%A3%E5%8C%96%EF%BC%86%E6%97%A5%E8%A8%98%E3%83%AD%E3%82%AC%E3%83%BC/gas/index.html
2. Apps Script のタブで `index.html` を開き、中央をクリック → **Ctrl+A** → **Ctrl+V** で、ひな形をすべて置き換える
3. **Ctrl+S** で保存する

左側の「ファイル」の下が、次の2つになっていれば完了です。

```
コード.gs
index.html
```

## 4. 初期設定（setup）を一度だけ実行する

1. `コード.gs` を開く
2. 上部のツールバーにある **「実行」ボタンの右の選択欄**（最初は `doGet` などが表示されている）を押し、一覧から **`setup`** を選ぶ
3. **「▷ 実行」** を押す
4. 「承認が必要です」という画面が出たら **「権限を確認」** を押し、自分のアカウントを選ぶ
5. 「このアプリは Google で確認されていません」と出たら、
   左下の **「詳細」** → **「習慣化ログ（安全ではないページ）に移動」** → **「許可」**（または「続行」）
   - 自分で作った自分専用のスクリプトなので問題ありません。スプレッドシートと Drive の読み書き、トリガーの作成の許可を求めています
6. 画面下に「実行ログ」が開き、**「初期設定が完了しました」** と出れば成功

これで Google Drive に次のものができます。

- フォルダ **「習慣化ログ」**
- その中のスプレッドシート **「習慣化ログ_データ」**（記録の本体）
- 毎日0時台に動くトリガー `dailyJob`（左端の時計のアイコン「トリガー」で確認できる）

`setup` はもう一度実行しても記録は消えません（トリガーを作り直すだけです）。

## 5. Webアプリとして公開する

1. 右上の青い **「デプロイ」** → **「新しいデプロイ」**
2. 左上の「種類の選択」の横の **歯車** → **「ウェブアプリ」**
3. 次のように設定して **「デプロイ」**
   - 説明：`初版`（何でもよい）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**
4. 表示された **「ウェブアプリ」の URL**（`https://script.google.com/macros/s/……/exec`）の下の「コピー」を押す
5. 試しに PC のブラウザの新しいタブに貼り付けて開き、ダッシュボードと「今日の記録」が表示されることを確かめる

## 6. iPhone のホーム画面に追加する

1. コピーした URL を iPhone に送る（自分宛てのメール、メモの共有、LINE の自分用トークなど）
2. iPhone でその URL を **Safari** で開く（LINE などの中のブラウザではなく Safari。開けないときは URL を長押し →「Safari で開く」）
3. Google のログイン画面が出たら、手順1と同じアカウントでログインする
4. アプリの画面が表示されたら、画面下の **共有ボタン**（四角から上向きの矢印）→ **「ホーム画面に追加」** → 名前を `習慣化ログ` にして **「追加」**

### うまく開けないとき

- **「ファイルを開くことができません」「現在、ファイルを開くことができません」と出る**：Safari で複数の Google アカウントにログインしていると起きることがあります。https://accounts.google.com で他のアカウントからログアウトし、手順1のアカウントだけにしてから開き直してください。
- **「読み込めませんでした。初期設定がまだです」と出る**：手順4の `setup` を実行してください。
- **画面が真っ白／「スクリプト関数が見つかりません: doGet」と出る**：`コード.gs` の貼り付けか保存ができていません。手順2をやり直し、保存してから「デプロイ」→「デプロイを管理」で新バージョンを作ってください（下の「コードを更新したとき」）。
- **画面に「index」が見つからないというエラーが出る**：HTMLファイルの名前が `index` になっているか確認してください。

## コードを更新したとき

エディタでコードを貼り替えて保存したあと、
**「デプロイ」→「デプロイを管理」→ 右上の鉛筆（編集）→ バージョン「新バージョン」→「デプロイ」**。
URL は変わらないので、ホーム画面のアイコンはそのまま使えます。

## 手元での確認（開発用）

Node.js があれば、GAS に貼り付けなくても動作を確かめられます。

```sh
node dev/test-server.js      # サーバー側のテスト
node dev/preview-server.js   # http://localhost:8080/ でサンプルデータ入りの画面を表示
```
