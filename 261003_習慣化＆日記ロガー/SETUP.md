# 導入手順（Google Apps Script ＋ iPhone）

PC のブラウザで 1〜5 を行い、最後に iPhone でホーム画面に追加します。所要時間は15分ほどです。

## 1. プロジェクトを作る

1. https://script.google.com を開き、記録に使う Google アカウントでログインする
2. 左上の「新しいプロジェクト」を押す
3. 上部の「無題のプロジェクト」を押し、名前を `習慣化ログ` に変える

## 2. 設定を変える

1. 左端の歯車（プロジェクトの設定）を開く
2. 「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェックを入れる
3. タイムゾーンが「(GMT+09:00) 東京」になっていなければ変える

## 3. コードを貼り付ける

左端の `< >`（エディタ）に戻り、このフォルダの `gas/` の中身を次のように貼り付けます（各ファイルの中身をすべて置き換える）。

| エディタ上のファイル | 貼り付ける中身 | 作り方 |
|---|---|---|
| `コード.gs` | `gas/Code.gs` | 最初からある |
| `Util.gs` | `gas/Util.gs` | 「ファイル」の横の＋ →「スクリプト」→ 名前 `Util` |
| `Data.gs` | `gas/Data.gs` | ＋ →「スクリプト」→ 名前 `Data` |
| `Export.gs` | `gas/Export.gs` | ＋ →「スクリプト」→ 名前 `Export` |
| `index.html` | `gas/index.html` | ＋ →「HTML」→ 名前 `index`（`.html` は自動で付く） |
| `appsscript.json` | `gas/appsscript.json` | 手順2で表示されたもの |

貼り付けたら、上部のフロッピーのアイコン（または Ctrl+S / ⌘+S）で保存します。

## 4. 初期設定（setup）を一度だけ実行する

1. 上部の関数の選択欄で `setup` を選び、「実行」を押す
2. 「承認が必要です」→「権限を確認」→ 自分のアカウントを選ぶ
3. 「このアプリは Google で確認されていません」と出たら「詳細」→「習慣化ログ（安全ではないページ）に移動」→「許可」
   - 自分で作った自分専用のスクリプトなので問題ありません。スプレッドシートと Drive の読み書き、トリガーの作成の権限を求めます
4. 実行ログに「初期設定が完了しました」と出れば成功

これで Google Drive に次のものができます。

- フォルダ「習慣化ログ」
- その中のスプレッドシート「習慣化ログ_データ」（記録の本体）
- 毎日0時台に動くトリガー `dailyJob`（左端の時計アイコンで確認できる）

`setup` はもう一度実行しても記録は消えません（トリガーを作り直すだけです）。

## 5. Webアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 歯車（種類の選択）→「ウェブアプリ」
3. 次のように設定して「デプロイ」
   - 説明：`初版`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**
4. 表示された「ウェブアプリ」の URL（`https://script.google.com/macros/s/…/exec`）をコピーする

## 6. iPhone のホーム画面に追加する

1. コピーした URL を iPhone に送り（メモやメールなど）、**Safari** で開く
2. Google のログイン画面が出たら、手順1と同じアカウントでログインする
3. アプリの画面が表示されたら、下部の共有ボタン（□に↑）→「ホーム画面に追加」→ 名前を `習慣化ログ` にして「追加」

### うまく開けないとき

- 「ファイルを開くことができません」「現在、ファイルを開くことができません」と出る場合：Safari で複数の Google アカウントにログインしていると起きることがあります。https://accounts.google.com で他のアカウントからログアウトし、手順1のアカウントだけにしてから開き直してください。
- 「読み込めませんでした。初期設定がまだです」と出る場合：手順4の `setup` を実行してください。

## コードを更新したとき

エディタでコードを貼り替えて保存したあと、「デプロイ」→「デプロイを管理」→ 鉛筆（編集）→ バージョン「新バージョン」→「デプロイ」。URL は変わらないので、ホーム画面のアイコンはそのまま使えます。

## 手元での確認（開発用）

Node.js があれば、GAS に貼り付けなくても動作を確かめられます。

```sh
node dev/test-server.js      # サーバー側のテスト
node dev/preview-server.js   # http://localhost:8080/ でサンプルデータ入りの画面を表示
```
